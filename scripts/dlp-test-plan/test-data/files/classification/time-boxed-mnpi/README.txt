Time-boxed sensitivity: pre- vs post-publication

Two parts, and the files below serve part (2).

(1) Effective-date window
    Apply a policy with a start and end date, move ANY file from this library
    inside the window, then again after it closes. Pass = enforcement changes
    with the calendar and the policy is not rewritten. Most tools cannot do this,
    so write down the workaround you had to use.

(2) Forecast vs published
    projected_fy27-revenue.xlsx   MNPI - board plan case, never filed
    published_fy25-results.xlsx   public - filed with the 10-K

    Same workbook shape, same sheet names, same segments, similar magnitudes.
    Only the Notes sheet and the forward-looking nature differ. A keyword-only
    tool will treat them identically; that is the point of the pair.
