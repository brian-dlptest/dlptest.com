**Kiteworks**, the private content and data exchange security platform, acquired **Bonfy.AI**, a young Israeli startup that emerged from stealth roughly a year ago with a $9.5 million seed round. Terms weren't disclosed. Reports differ slightly on the announcement date (Let's Data Science cited September 8, Help Net Security and AI Weekly cited September 11), but they agree on the deal.

Bonfy does real-time data classification and contextual policy enforcement for both human and AI agent workflows, across email, file sharing, SaaS applications, and API and agent traffic. Kiteworks has been strong on static classification and governed content exchange, and this gets it to data *in motion and in use*, including traffic from AI agents.

It's a small deal compared to the mega-rounds elsewhere this year, but it matters if you're looking at platforms for AI-era data governance. A lot of vendors are buying "AI agent guardrails" right now so that traffic doesn't go uninspected. If you're already on Kiteworks, expect runtime classification to show up in future releases.
