**Snowflake** completed an Infosec Registered Assessors Program assessment at the **PROTECTED** level for its deployment in **Google Cloud's Melbourne region**, according to coverage of the company announcement.

IRAP assessments are used by Australian public-sector organizations to evaluate whether systems meet security-control expectations set by the Australian Signals Directorate. Snowflake says the Google Cloud assessment follows earlier IRAP work for AWS and Azure, giving customers a three-hyperscaler option set for sensitive workloads.

### Why It Matters

The announcement is not a new DLP or DSPM feature, but it is meaningful for cloud data security. Public-sector agencies and regulated enterprises increasingly need to show that analytics and AI workloads run on governed data foundations, in approved regions, with auditable controls.

### Data Security Lens

Snowflake emphasized secure data sharing, governed collaboration, and support for AI and advanced analytics on sensitive data. That places IRAP status in the same buying conversation as sovereignty, classification, access governance, and data-residency controls.

### Competitive Context

Cloud data platforms are becoming part of the AI security perimeter because agents and analytics services need governed access to sensitive information. Certifications and assessments do not replace posture management, but they shape which platforms are allowed to host high-value datasets in the first place.
