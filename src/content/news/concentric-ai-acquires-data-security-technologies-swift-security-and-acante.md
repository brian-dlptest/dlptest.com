Concentric AI acquired two AI security startups, Swift Security and Acante, to add to its data security governance platform. The goal is to bring data security posture management (DSPM), data loss prevention (DLP), and generative AI (GenAI) governance together across data types and environments.

Here's what it gets:

- **More GenAI coverage:** Swift Security and Acante extend Concentric AI's protections across multiple GenAI use cases, covering enterprise data at rest, in motion, and in use.
- **Monitoring public GenAI tools:** With Swift Security's technology, Concentric AI can now monitor and prevent data exfiltration across public GenAI tools like ChatGPT, along with governing proprietary GenAI workloads.
- **More data governance:** The deals add to Concentric AI's Semantic Intelligence platform, which handles discovery, categorization, classification, risk monitoring, and protection of enterprise data.
