**Obsidian Security** introduced a Runtime Policy Decision Engine that gives security teams centralized control over AI agent actions before they run. The engine pulls context from a company's apps, identity systems and its own data labels into one decision point, so each enforcement point applies a decision before an agent's action reaches the app.

Coverage now extends to coding and chat agents. Obsidian says its runtime policy enforcement applies the same policies to OpenAI Codex, Claude Code, Cowork and Microsoft Copilot from one console.

Obsidian has built its name on SaaS security posture management. This move pushes the product from discovery-only visibility toward runtime enforcement, a gap most SSPM tools haven't closed yet.
