**Denodo** announced new integrations with **Amazon Web Services** intended to make enterprise data usable by AI agents without losing governance context. The company framed the problem as a data issue rather than a model issue: agents fail in production when they operate on stale, incomplete, or poorly governed information.

### What Was Announced

The integrations span **Amazon SageMaker**, **Amazon Bedrock AgentCore**, and **Amazon QuickSight**. Denodo says its logical data layer can provide live, zero-copy access to operational and analytical data across on-premises, SaaS, and multi-cloud environments.

The Bedrock AgentCore integration is especially relevant for security teams because it ties agent access to governed data definitions, business context, authentication, and policy enforcement. Denodo also highlighted Model Context Protocol support as part of the access pattern.

### Why It Matters

Agentic AI raises a familiar data-security question in a new form: who or what is allowed to query sensitive data, under which business meaning, and with what audit trail? Denodo's announcement sits in the growing overlap between data virtualization, semantic governance, and AI runtime control.

### Data Security Lens

The announcement is not a standalone DSPM product launch, but it addresses a closely related requirement: making sensitive-data access understandable and enforceable before agents use it. If buyers move agent governance closer to the data layer, data catalogs, DSPM platforms, and cloud security tools will increasingly need to prove how their policies survive real-time agent workflows.
