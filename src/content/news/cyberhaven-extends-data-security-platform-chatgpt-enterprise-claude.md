**Cyberhaven** added compliance API integrations for OpenAI's ChatGPT Enterprise and Anthropic's Claude Enterprise, which give security and compliance teams visibility into conversations, uploaded files, and workspace activity in both tools. (Disclaimer: I work at Cyberhaven.)

The integrations use the ChatGPT Enterprise Compliance API and Claude Compliance APIs to monitor, inspect, and classify sensitive data *already inside* each platform. That's data at rest in the AI tool, not just data in motion. Browser and endpoint controls can inspect content as it moves into an AI app, but they can't always see what's already in Claude or ChatGPT Enterprise: old conversations, uploaded files, custom GPT and Projects configurations, sharing permissions, and user activity.

So this adds a DSPM-style layer for GenAI workspaces on top of Cyberhaven's endpoint and browser DLP. The question for buyers is if API-based scanning of AI transcripts becomes something every DLP and DSPM vendor has to match, and how it fits with runtime prompt controls like the ones covered here from Microsoft Purview and Fortinet.

This is a vendor product announcement, so treat the capability and adoption claims as vendor claims until there's independent testing. Most endpoint-first DLP still doesn't cover what's already built up inside enterprise AI tools.
