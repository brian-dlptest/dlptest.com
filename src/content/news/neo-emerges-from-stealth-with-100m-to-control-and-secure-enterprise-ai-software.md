**Neo Security** came out of stealth this week with $100M in total funding, the largest single number yet in agentic access governance. That's a $75M Series A co-led by Andreessen Horowitz and Bessemer Venture Partners, with Craft Ventures and Merlin Ventures participating, on top of a previously undisclosed $25M seed from 2025.

The founders are notable. CEO Nick Warner is the former president/COO of **SentinelOne**, CPO Shlomi Salem led detection engineering there, and Eran Shirazi is CTO. Angels include Wiz's Assaf Rappaport.

The product is a real-time control layer for agentic software. It inventories the tools and agents running across an enterprise, checks if they're safely configured, and enforces policy before risky activity happens. The hard part is that agents typically act with a valid user's permissions. So the exposure isn't a stolen credential. It's a legitimately authorized agent doing something it shouldn't with data it can already reach.

**Why data protection teams should care.** This isn't a classic DLP or DSPM engine. It bridges endpoint, network, and identity. But the data exposure is real. In March, Neo's team published research on an accounting firm leak that exposed schemas, API keys, and auth tokens, exactly the kind of data agents run into. Once agents have write access to CRMs, code repos, and file stores, "what data can this agent touch, and under whose authority" is a data security question, even if it doesn't live in a DSPM console.

**Where it fits.** Neo joins a string of recent agentic security deals, including Straiker, Archestra, Zscaler's Symmetry buy, and Cisco's Astrix pickup. Agentic access governance is becoming its own budget next to DLP and DSPM, but not inside them yet. Expect overlap with your existing data security tools.
